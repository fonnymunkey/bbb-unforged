# Betterer Biomer Blender
[Betterer Biomer Blender](https://www.curseforge.com/minecraft/mc-mods/bbb-unforged) is a client-side mod which improves biome blending
This is a fork of [Better Biome Blend](https://www.curseforge.com/minecraft/mc-mods/better-biome-blend) 1.12.2 in order to update to use more modern mixin and clean up various issues/crashes
